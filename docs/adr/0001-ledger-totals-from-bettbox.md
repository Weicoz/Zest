# 0001 链路账本总量取 Bettbox 自报总量，差额记为未归属

日期：2026-11-20。状态：已采纳。

## 背景

链路账本靠轮询 Bettbox `GET /connections`，按连接 id 累加增量。spike（`spikes/001-bettbox-ledger/README.md`）实测：排除内部连接后，下行覆盖 99.6–99.7%，上行只有 83–87%。两次轮询之间关闭的短连接，收尾字节记不到。

## 决定

- 总量取 Bettbox 自报的 `downloadTotal` / `uploadTotal` 差分。
- 按规则、出口、应用、域名的分布取逐连接差分。
- 两者之差单列为「未归属」，不按比例摊给各规则。
- 内部连接（`metadata.type == "Inner"`）不计入。

## 备选

- 只用逐连接差分：总量偏小，上行偏差约 15%。
- 按比例摊派差额：数字好看，但把猜测伪装成事实。
- 改订 WebSocket 推送：可缩小漏记窗口，未验证，留待后续。

## 影响

各规则之和不等于总量，界面必须显示「未归属」一行。Bettbox 重启时自报总量清零，差分须按负值视为重启处理。
