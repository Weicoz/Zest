# 05: 链路搜索、筛选与 CSV 导出

## 偏差

- 域名搜索只缩小「按域名」列表与实时链路表；汇总、柱图、规则/出口/应用卡片只按规则、出口、应用匹配（日汇总与小时数据没有域名）。搜索域名时这些汇总可能为 0。
- 未归属行只在「全部」且搜索为空时显示、计入总量与 CSV；其余筛选下隐藏。
- CSV 表头用票据给出的中文列名，下载、上传列写作「下载字节」「上传字节」（单位字节，与流量喵一致）。流量喵原版另有「协议」列且全字段加引号、带公式前缀转义；本票按 RFC 4180 只在需要时加引号，不加公式前缀。导出文件带 UTF-8 BOM（便于 Excel 识别中文）。
- 地址、端口、规则载荷、策略链库里未持久化，列保留且值留空，未改表结构。
- 小时列恒为空：域名与日汇总均按天存，小时表无域名。CSV 行尾用 CRLF。
- 导出在主线程只读打开库并查询（范围至多一个月）；规模变大再挪到后台。
- 未启动 build/Zest.app 截图，界面未看画面。
- 审查修复：搜索词非空时，30 天内的日期改用域名日记录重算规则、出口、应用汇总、总量与按天柱图（命中域名或规则、出口、应用），更早日期只按规则、出口、应用匹配；页面写一行提示。小时柱图无域名数据，搜索时只按规则、出口、应用匹配（最小方案）。当前范围最长一个月，实际很少出现超 30 天日期。
- 「仅代理」只算真实代理节点：排除 DIRECT、REJECT 系（前缀 REJECT）与空出口。
- CSV 文本列以 = + - @ Tab 回车开头时加 ' 前缀（数字列不加）。
- 库打不开或写文件失败时弹双语提示。
